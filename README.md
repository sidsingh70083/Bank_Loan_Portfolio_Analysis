# 🏦 Bank Loan Portfolio Analysis and Dashboarding

This project is a comprehensive deep dive into a bank's lending portfolio, designed to move beyond raw metrics and provide strategic, actionable intelligence. It was developed to empower stakeholders to **proactively manage credit risk**, optimize resource allocation, and drive profitability.

## Project Goal & Strategic Value

The primary objective was to transform raw financial data into a dynamic, interactive **Power BI dashboard** that serves as a single source of truth for portfolio health.

The analysis is specifically focused on:
* **Risk Mitigation:** Clearly identifying the profile and volume of **Bad Loans Issued** (13.8% of applications) versus **Good Loans Issued** (86.2%) to refine lending criteria.
* **Performance Tracking:** Monitoring key performance indicators ($KPI$s) like **Total Funded Amount** ($435.8M$) and **Total Amount Received** ($473.1M$) against monthly targets ($MTD$) and Month-over-Month ($MoM$) changes.
* **Behavioral Insights:** Visualizing the distribution of loans by **Purpose** (e.g., Debt Consolidation, Credit Card) and **Geography** to uncover regional lending opportunities or risks.

## Dashboard Highlights and Key Metrics

The solution is an interactive dashboard structured across Summary, Overview, and Detail pages, including:

* **Loan Quality Breakdown:** A clear visual split between Good Loan ($86.2\%$) and Bad Loan ($13.8\%$) applications.
* **Monthly Trend Analysis:** Visualization of **Total Loan Applications by Month**, showing continuous growth from January to December.
* **Loan Term Distribution:** Analysis of term preferences (36 months vs. 60 months), with 36-month terms accounting for the majority ($73.2\%$ or $28K$ applications).
* **Detailed Risk Indicators:** Snapshot of Average Interest Rate ($12.0\%$) and Average Debt-to-Income ratio ($DTI$, $13.3\%$).
